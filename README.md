# 발로란트 스타일 FPS 게임

Three.js와 WebGL을 사용한 3D 일인칭 슈팅 게임입니다. 리얼리스틱한 그래픽, 상세한 NPC AI, 그리고 디테일한 환경을 특징으로 합니다.

## 주요 기능

### 게임플레이
- **FPS 컨트롤**: WASD 이동, 마우스 조준, 클릭으로 사격
- **리얼리스틱 무기 시스템**: 반동, 재장전, 탄약 관리
- **AI NPC**: 순찰, 추적, 공격 등 지능적인 AI 행동
- **체력 시스템**: 플레이어와 NPC 모두 체력 관리

### 그래픽
- **고품질 3D 렌더링**: Three.js 기반 WebGL 렌더링
- **리얼리스틱 조명**: 태양광, 환경광, 반구광, 그림자
- **상세한 환경**: 건물, 나무, 엄폐물, 장식 오브젝트
- **디테일한 NPC 모델**: 머리, 몸통, 팔, 다리, 무기, 헬멧 등

### UI/UX
- **크로스헤어**: 정확한 조준을 위한 십자선
- **HUD**: 체력바, 탄약, 처치 카운터
- **시각적 피드백**: 피격 효과, 총구 화염, 히트 마커

## 시작하기

### 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm start
```

또는

```bash
npm run dev
```

게임이 자동으로 브라우저에서 열립니다 (http://localhost:8080)

### 프로덕션 빌드

```bash
npm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다.

## 게임 조작법

- **W/A/S/D**: 이동
- **마우스**: 시점 회전
- **왼쪽 클릭**: 사격
- **R**: 재장전
- **Shift**: 달리기
- **Space**: 점프

## 게임 구조

```
src/
├── main.js          # 엔트리 포인트
├── Game.js          # 메인 게임 로직
├── Player.js        # 플레이어 컨트롤러
├── Weapon.js        # 무기 시스템
├── NPC.js           # NPC AI 및 모델
├── Environment.js   # 3D 환경 및 맵
├── UI.js            # 사용자 인터페이스
└── index.html       # HTML 템플릿
```

## 기술 스택

- **Three.js**: 3D 그래픽 렌더링
- **WebGL**: 하드웨어 가속 그래픽
- **Webpack**: 모듈 번들러
- **JavaScript (ES6+)**: 게임 로직

## 게임 특징

### 환경 디테일
- 5개의 서로 다른 건물 (본부, 중간 건물, 작은 건물, 긴 건물, 타워)
- 각 건물에 창문과 옥상 디테일 (에어컨 실외기 등)
- 나무들 (줄기와 여러 층의 나뭇잎)
- 엄폐물 (상자, 드럼통)
- 경계 벽

### NPC 디테일
- 상세한 3D 모델 (머리, 헬멧, 눈, 몸통, 팔, 다리)
- 무기 장착
- 체력바 표시
- 3가지 AI 상태: 순찰, 추적, 공격
- 사실적인 사격 메커니즘 (명중률 70%)

### 게임 메커니즘
- 충돌 감지 (건물, 오브젝트, 경계)
- 중력 및 점프 물리
- 무기 반동 및 흔들림 효과
- NPC 자동 스폰 (최대 10명)
- 킬 카운트 및 점수 시스템
